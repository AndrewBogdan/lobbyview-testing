
This is the data directory for this project. Go to [LobbyView](https://www.lobbyview.org/) and download all the data.
Paste the following `.csv` files into this directory:

- `bills.csv`
- `clients.csv`
- `issue_text.csv`
- `issues.csv`
- `lobbyists.csv`
- `network.csv`
- `reports.csv`

I downloaded everything into the `/Codebooks` directory, which is ignored by git, so that I would have the codebook
pdfs available if I need them. I'm using the v2024.10.01 datasets, which you can check via `version.pdf` in your
downloads.

Sorry to give you extra work, but the data is 2.3 GB, too large to commit to git.
